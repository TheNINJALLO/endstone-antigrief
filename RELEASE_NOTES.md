# AntiGrief v1.5.13

This release packages the current BlockData-powered AntiGrief system as a complete public project. It includes exact container and player inventory snapshots, recursive bundle inspection, coordinated rollback, verified item recovery, printable grief reports, UTF-8-safe inventory fallback, full operator documentation, GitHub Pages documentation, Wiki source, CI, and automated wheel releases.

## Required runtime

- BDS 1.26.33.1
- Endstone 0.11.6
- Python 3.14
- BlockData API 0.4.8 or newer, using the matching native plugin and inspector wheel

Back up the world and `plugins/antigrief_data/agdata.db` before upgrading or performing a production rollback.
